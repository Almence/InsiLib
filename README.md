## Apa itu InsiLib?

InsiLib adalah website peminjaman buku dalam lingkup perpustakaan sekolah. Dengan berbagai fitur yang memudahkan akses siswa saat meminjam buku, InsiLib hadir dengan mengedepankan kemudahan navigasi, otomatisasi, dan QR Code buku. Menggantikan cara lama dengan yang baru dan efektif adalah langkah kemajuan teknologi. Beberapa diantaranya adalah:
<ul>
    <li>Pembuatan Laporan Bulanan.</li>
    <li>Pencetakan QR Code per-buku/</li>
    <li>Indeks buku dengan filter dan search.</li>
    <li>Peminjaman yang di-otomatisasi.</li>
</ul>
